# Cryptography in Online Multiplayer Games

An animated presentation on encryption, authentication and digital ownership in online games, plus a hands-on **Crypto Lab** that runs real cryptography (AES-GCM, X25519, HMAC, Ed25519) in the browser.

- **Presentation:** `index.html`. Use ← → (or click / swipe) to navigate, **F** for fullscreen, **N** for speaker notes.
- **Crypto Lab:** `lab/`. Encrypt and tamper with a packet, run a key exchange with a man in the middle, forge a token, replay packets, and try to duplicate an item on a signed ledger.

Presenters: Nikhil Simon Toppo · Abhishek Joshi · Abhinav Kumar
